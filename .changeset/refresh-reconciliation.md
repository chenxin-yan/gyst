"@gyst/cli": minor

Refresh without losing surviving review work. `gyst session refresh` now takes `--snapshot` (the snapshot it replaces) and `--request-id`, replies with the previous and new snapshot ids and whether the capture replaced anything, and answers a retry of the same request with its recorded result. An identical capture keeps the snapshot, revision and progress. Guidance is no longer dropped: groups that lost every hunk stay in place, notes move with code that only shifted, and guidance whose code or referenced lines changed is kept and marked `outdated`, which `status` lists under `preparation` and which keeps the walkthrough incomplete. Agents revalidate unchanged wording with `walkthrough.revalidate`, `group.revalidate` and `note.revalidate`. `session check` reports the snapshot it compared, and `files`/`code` also read earlier snapshots that guidance still pins. In the browser viewer, `R` refreshes the session (a lost reply is retried without refreshing twice), the command menu checks the source, Outdated guidance says so and why, and notes whose code is gone show their earlier captured lines on request. Sessions saved by earlier versions are not migrated.
