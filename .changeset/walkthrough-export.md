Export a complete walkthrough as one standalone, read-only HTML file, from the viewer's Export… dialog or `gyst session export --session <id> [--output <file>]`. Both show every file side it will carry with its content identity (changed files in full and the files guidance references, older pinned ones included), the references it cannot show and why, the recorded scope with the resolved commits (a three-dot range's merge base, HEAD or an empty baseline for uncommitted work) and a warning that full files and guidance may disclose secrets, and generate the file only for exactly the state a person approved: a change meanwhile refuses the approval. The CLI needs an interactive terminal and a typed `yes`, never replaces an existing file and leaves nothing behind on a failed write, or names the file it could not take back. Only a complete walkthrough exports: no partial or Outdated override. The file opens offline without gyst or the checkout, makes no network request and carries no conversations, Viewed progress, session id or local paths.
