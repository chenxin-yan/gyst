Add `@gyst/navigation-typescript`, the optional TypeScript/JavaScript navigation add-on, released at exactly the same version as `@gyst/cli`. Its `gyst-navigation-typescript` executable reports its release and checks its pinned TypeScript 7.0.2 engine with `--version`, and starts that engine's language server only for the matching gyst release. It is not installed with gyst.
